OUR SERVICES

Engineering services from design to implementation.

We work across Allen-Bradley, Siemens and Schneider platforms, and provide value services that our clients rely on most.

System design and specification

  • System performance objectives
  • Conceptual design and system architecture
    • Site and system specifications
    • Compliance with local and reference standards
  • Scope definition
  • Customer / vendor coordination
  • Optimum system selection and specification

System engineering

  • System architecture design
  • Detailed functional specifications
  • System interconnection diagrams & one-line electrical drawings
  • Power distribution schemes and system load calculations
  • Control narratives, loop diagrams, plant control loops, functional body diagrams
  • Alarms, logic & safety interlocks

Detailed software engineering

  • Detailed functional specifications & network load calculations
  • System parameter configuration details
  • Software programming
    • PLC programming
    • SCADA / HMI engineering
    • Networking and data logging

Detailed hardware engineering

  • Panel & cabinet design — dimension, layout, cutout, base and wiring drawings
  • Bill of materials / take-off list
  • Procurement, fabrication and integration

Field engineering

  • Panel lists and I/O lists from P&ID
  • Field instrumentation specification & selection
  • Documentation — location drawings, instrument hookup drawings, junction box schedules, control room layouts, cable schedules and routing drawings

System analysis and testing

  • Support safety and reliability analyses — HAZOP / LOPA / SIL
  • Hardware FAT
  • Software FAT with hardware integration

Project engineering

  • Documentation, approvals and reporting
  • Online and offline support through the project
  • Online and offline support post-commissioning

Commissioning engineering

  • Integration and mechanical completion support
  • Cold and hot commissioning
  • Site Acceptance Testing (SAT)
  • Operator training and certification
